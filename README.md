## 使用方法
### テキストを入力する
ウインドウのカーソル部分などをクリックしてから入力します。
文字を消すときは`←`(BackSpace)キーを押します。
### テキストを貼り付ける
`ctrl+v`を押すと貼り付けられます。
### ローマ字を変換する
`ctrl+J`を押すことでその行が日本語化されます
### ファイルを読み込む
左上の**Open File**ボタンを押してからファイルを選択します。
### ファイルを保存する
左上2番目の**Save File**ボタンを押してファイル名を設定してから保存します
### ファイル名を変更する
入力欄の上のボックスに入力します。
テキスト側にも入力されるので消してください
### 設定を開く
右上の**Open Settings**を押します。ここからテーマを選択でき、テーマは次回の訪問時も保持されます。
