## 使用方法
### テキストを入力する
ウインドウのカーソル部分などをクリックしてから入力します。
文字を消すときは`←`(BackSpace)キーを押します。
### テキストを貼り付ける
`ctrl+v`を押すと貼り付けられます。
### ローマ字を変換する
`ctrl+J`を押すことでその行が日本語化されます
### コードを実行する
コードを入力してから下の`Exec`ボタンを押してください
### 変数名を確認する
水色の`vars`という表を確認してください

### ファイルを読み込む
左上の**Open File**ボタンを押してからファイルを選択します。
### ファイルを保存する
左上2番目の**Save File**ボタンを押してファイル名を設定してから保存します
### ファイル名を変更する
入力欄の上のボックスに入力します。
テキスト側にも入力されるので消してください
### 設定を開く
右上の**Open Settings**を押します。ここからテーマを選択でき、テーマは次回の訪問時も保持されます。
## QA
Q:Tab文字が横棒になっているのはなぜですか

> A:プログラミングでインデント(深さ)をわかりやすくするためです。ダウンロード時などはTabのままなのでご安心ください。

Q:varsの表に打消しされた赤くなっている変数があります。どうすればいいですか？

> A:赤い波下線がある部分の部分にエラーがあります。指示に従って修正してください
また、行数(`2行目` など)をクリックするとコードの場所が表示されます。

Q:「内部エンジンがエラーを予測したため、実行は中止されました」と出ました

> A:実行前にエディターがエラーを検出したため、安全のため実行しませんでした。
指示に従ってすべてのエラーを修復してください

Q:`[fileReading][ERR] Failed to execute 'showOpenFilePicker' on 'Window': The user aborted a request`ってエラーが出ました

> A:ユーザーがファイル選択をキャンセルしたときのエラーが出ます。自動化する予定ですのでしばらくお待ちください。

Q:バグを見つけました。どうすればいいですか？

> A:報告してください。
